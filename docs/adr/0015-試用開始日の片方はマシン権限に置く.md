# ADR 0015: 試用開始日の片方はマシン権限に置く

- 状態: 有効
- 日付: 2026-09-18

## 文脈

[ADR 0013](0013-試用開始日はPC側に残す.md) は試用開始日を `HKCU` と `%LocalAppData%` へ二重書きした。どちらも **同一 Windows ユーザーの権限** なので、そのユーザーは両方消せる。システム環境変数も候補だが、書き込みに管理者権限が要り、標準ユーザーでは記録自体が残らない。

## 決定

権限の境界が違う場所へ書く。欠け側・遅い側へ、より早い初回日を書き戻す。UAC は出さない。

- マシン: `HKLM\Software\PdfSignage\`（管理者に昇格したときだけ書ける。標準ユーザーは読むだけ）
- マシン: `%ProgramData%\PdfSignage\trial.dat`（昇格なしで書ける PC 単位のファイル）
- ユーザー: `HKCU\Software\PdfSignage\` と `%LocalAppData%\PdfSignage\trial.dat`（従来どおり）

システム環境変数には置かない。

## 理由

- ユーザー領域だけだと、再インストール制限が「知っていれば外せる」同じ権限のコピーになる
- HKLM は標準ユーザーが消せない。一度でも昇格起動した PC では、AppData と HKCU を消しても延びない
- ProgramData は昇格なしで PC 単位に残る。別 Windows ユーザーやプロファイル削除では消えない（作った本人は消せる）
- 標準ユーザーのみでも HKCU と LocalAppData があるので、起動は落ちない

## 検討した代替案

**システム環境変数** — 管理者権限が要る点は HKLM と同じだが、全プロセスに値が渡り、システムの環境変数画面にも出る。却下。

**ユーザー環境変数** — HKCU と同じ権限。境界が増えない。却下。

**常時 UAC / `requireAdministrator`** — キオスクの自動起動と合わない。

**ProgramData だけ（HKLM なし）** — 作ったユーザーが消せるので、同一ユーザーの権限問題が残る。

## 結果

本格 DRM にはしない。OS 再インストール、別 PC、管理者による HKLM と ProgramData の削除は新しい 60 日。昇格したことがない PC で、本人がユーザー領域と ProgramData を全部消した場合も同じ。
