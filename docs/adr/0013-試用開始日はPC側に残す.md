# ADR 0013: 試用開始日は PC 側に残す

- 状態: 有効（保存先は [0015](0015-試用開始日の片方はマシン権限に置く.md) で改訂）
- 日付: 2026-09-12

## 文脈

試用は初回起動から暦日 60 日（[課金方針](../課金方針.md)）。設定とコンテンツはポータブル配布のため exe 横の `settings.json` に置く（[ADR 0005](0005-設定ファイルを-exe-と同じ場所に置く.md)）。試用開始日までそこに混ぜると、フォルダ削除や `settings.json` 消去で 60 日をやり直せる。一方、端末指紋やオンライン認証はオフラインキオスクと信頼ベースの台数方針に合わない。

## 決定

試用開始日だけを、exe フォルダの外へ二重書きする。

- `HKCU\Software\PdfSignage\`（自動起動と同じ Windows ユーザー単位）
- `%LocalAppData%\PdfSignage\` のマーカーファイル

片方を消しても **より早い初回日** を採用する。平文の日付は置かない（メモ帳感覚で延ばせない程度の難読化。本格 DRM にはしない）。

アクセスキーは従来どおり `settings.json` に置く。フォルダ複製で全台へ同じキーが乗る。

## 理由

- 同一 PC・同一ユーザーで設定や配布フォルダを消す「ただ乗り」は防げる
- 設定・コンテンツのポータブル複製（ADR 0005）は壊さない
- OS 再インストールや別 PC は新しい 60 日のままなので、現場の再セットアップで試用が死なない

## 検討した代替案

**`settings.json` だけに試用開始日を書く（課金方針 2026-09-03 時点）** — 消すだけで 60 日をやり直せる。撤回する。

**試用開始日も `settings.json` に混ぜ、リセットを仕様として受け入れる** — 短期イベントの使い直しには都合がよいが、常設のただ乗りを止められない。

**時計の最終確認日時も残す（巻き戻し対策）** — 軽量を超える。キオスク PC の日付ずれで正規顧客が切れる事故の方が高い。

**ハードウェア指紋・オンライン認証** — 再イメージで現場が止まる。台数は契約文言のみ、という方針と矛盾する。

## 結果

ADR 0005 の「AppData / レジストリに残骸を残さない」とは、**試用マーカーに限った例外** を切る。アンインストールがフォルダ削除だけでは完結しなくなる。

受け入れる残リスク: OS 再インストール、別 Windows ユーザー、別 PC、レジストリと AppData の両方削除は新しい 60 日。時計の巻き戻しは見ない。
