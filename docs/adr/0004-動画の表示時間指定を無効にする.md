# ADR 0004: 動画の表示時間指定を無効にする

- 状態: 有効
- 日付: 2026-08（MVP 開発時の判断を後追いで記録）

## 文脈

画像と PDF はファイル名末尾の `_秒数` で表示時間を指定できる。動画にも同じルールを適用するかを決める必要があった。「30 秒だけ流す」といった要望は想像できる。

## 決定

動画（`.mp4`）は再生完了まで表示する。`_秒数` は解析するがスライドには反映せず、`Slide.DisplaySeconds` は 0 に固定する。進行は `MediaElement.MediaEnded` のみで行い、タイマーは停止する。

## 理由

- 動画の途中で打ち切ると、たいていの場合は意味が通じない状態で切れる。掲示物として成立しない
- 指定秒数と動画の長さが食い違ったときの正解が決められない。短すぎれば途中で切れ、長すぎれば静止画で待つことになり、どちらも説明しづらい
- 「短くしたい」という要望に対しては、動画そのものを編集するという明快な答えがある

## 検討した代替案

**`_秒数` で打ち切る** — 一貫性はあるが上記のとおり掲示として破綻する。

**`_秒数` を「最低表示時間」として扱う（短い動画はループ）** — 挙動が複雑になり、利用者に説明できない。

**設定で切り替えられるようにする** — 管理画面の項目が増える。「誰でも運用できる」という MVP の方針に対して、得られるものが釣り合わない。

## 結果

進行の起点が**画像・PDF はタイマー、動画は `MediaEnded`** の 2 系統になった。`MainViewModel.RestartTimerForCurrentSlide()` が動画のときだけタイマーを止めているのはこのため。

再生に失敗した動画でループが止まらないよう、`MediaFailed` も `OnVideoEnded()` を呼ぶ経路にしてある（`MainWindow.VideoPlayer_MediaFailed`）。**このハンドラを外すと、壊れた動画で表示が永久に止まる。**

利用者向けには「動画だけ表示時間を短くしたい」を[操作ガイド](../操作ガイド.md)の FAQ に載せている。
