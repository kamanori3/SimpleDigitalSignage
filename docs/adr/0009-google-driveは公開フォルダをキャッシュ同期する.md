# ADR 0009: Google Drive は公開フォルダをローカルキャッシュへ同期する

- 状態: 有効
- 日付: 2026-09-04

## 文脈

管理画面に Google Drive のフォルダリンクを貼り、その中身をサイネージ表示したい。キオスクは Drive のウェブ UI（ログイン・ツールバー）と相性が悪い。既存の再生はローカルフォルダ前提である。

## 決定

フォルダ URL から ID を取り、Drive API で直下の JPEG / PDF / MP4 を exe 横の `DriveCache` へダウンロードする。表示は既存のスキャン・監視・プレイリストをそのまま使う。フォルダは「リンクを知っている全員が閲覧可」とし、認証は API キーのみとする。

## 理由

再生経路を増やさない。回線断でもキャッシュで継続できる。WebView2 は ADR 0001 で既に不採用。

## 検討した代替案

**Drive の画面を WebView で出す** — キオスクに不向き。ログイン壁がある。

**Google Drive for Desktop の同期フォルダを監視するだけ** — アプリ改修は少ないが、「リンクをアプリに設定する」要求とずれる。

**サービスアカウント / OAuth** — 制限フォルダは扱えるが、キオスクへのログインや鍵配布が増える。v1 では採らない。

## 結果

公開フォルダの URL を知っている第三者も中身を見られる。API キーは `settings.json` に保存され、exe をコピーされると漏洩しうる。クォータ監視が必要。制限付きフォルダは同期できない。
