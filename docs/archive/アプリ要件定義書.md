## 1. システム概要

### 1.1 システム名称

PDFサイネージシステム

### 1.2 目的

本システムは、指定フォルダに保存された PDF・画像・動画ファイルを自動的に表示し、デジタルサイネージとして利用することを目的とする。

利用者は、ファイルを所定フォルダへコピーするだけで表示内容を更新できるものとする。

### 1.3 想定利用シーン

- 大学の就職関連イベントのお知らせ

## 2. システム構成

### 2.1 ハードウェア構成

#### サイネージ端末

- Windows PC（2015年以降）
- HDMI 接続ディスプレイ（**シングルディスプレイ想定**）
- フル HD 以上推奨

#### ネットワーク

- 必須ではない
- ローカルフォルダ運用を基本とする
- 将来共有フォルダ運用に対応可能とする

### 2.2 ソフトウェア構成

#### OS

- **Windows 11 のみ**（Windows 10 は対象外）

#### アプリケーション

- PDF サイネージアプリ（自社開発）
- 開発言語・フレームワーク: **C# / WPF**
- 配布形態: **ポータブル exe**（インストーラー不要）

## 3. 機能要件

### 3.1 コンテンツ表示機能

#### 概要

指定フォルダ内の PDF・JPEG 画像・MP4 動画を読み込み、順番に表示する。

#### 表示対象（MVP）

| 種別 | 拡張子 |
|------|--------|
| PDF | `.pdf` |
| 画像 | `.jpeg`, `.jpg` |
| 動画 | `.mp4` |

#### 仕様

- ファイル名の自然順（数値を考慮したソート）で表示する
- デフォルトの表示時間は管理画面で設定できる（初期値 15 秒、範囲 5〜300 秒）
- **動画以外**（PDF・画像）は、ファイル名末尾の `_秒数` で個別の表示時間を指定できる
  - 例: `003_イベント案内_120.pdf` → 120 秒表示
  - 例: `ガイダンス_50.jpeg` → 50 秒表示
  - 末尾に `_秒数` がない場合はデフォルト表示時間を適用する
- **動画（MP4）** は再生を最後まで行い、終了後に次のコンテンツへ切り替える（表示秒数による打ち切りはしない）
- **PDF 複数ページ** は各ページを順に表示し、全ページ表示後に次のファイルへ進む
- 画像は画面中央にアスペクト比を維持して表示する（余白あり）
- 新規追加ファイルを自動認識する
- 削除されたファイルは表示対象から除外する

#### 表示対象例

```text
D:\Signage

001_会社方針.pdf
002_安全目標.pdf
003_イベント案内_120.pdf
004_案内動画.mp4
005_ポスター.jpg
```

#### 表示順の例

```text
001_会社方針.pdf（1ページ目 → 2ページ目 → …）
↓
002_安全目標.pdf
↓
003_イベント案内_120.pdf（120秒）
↓
004_案内動画.mp4（再生完了まで）
↓
005_ポスター.jpg
↓
001_会社方針.pdf（ループ）
```

---

### 3.2 自動切替機能

#### 概要

一定時間ごとに次のコンテンツへ切り替える（動画は再生完了時に切り替え）。

#### 初期設定

- 15 秒

#### 設定範囲

- 5 秒〜300 秒

#### 動作例

```text
PDF1
↓ 15秒
PDF2
↓ 15秒
PDF3
↓ 15秒
PDF1
```

---

### 3.3 ループ表示機能

#### 概要

最後のコンテンツ表示後、自動的に先頭へ戻る。無限ループとする。

#### 動作例

```text
PDF1 → PDF2 → PDF3 → PDF1 → PDF2 → …
```

---

### 3.4 フォルダ監視機能

#### 概要

表示対象フォルダを常時監視する。

#### 監視対象

- ファイルの追加・削除・更新（PDF / JPEG / MP4）

#### 動作

- 変更を検知した場合、**現在表示中のスライドの表示完了後**に表示リストへ反映する
- 監視対象は監視フォルダの**直下のみ**（サブフォルダは対象外）

#### スケジュール運用（MVP 含む）

- 管理画面で指定した時刻にアプリケーションを終了する
- 管理画面で指定した時刻に PC の電源をオフにする（`shutdown` コマンドで実行）
- 翌朝は Windows 起動時の自動起動（3.6）によりアプリが起動し、表示を開始する

---

### 3.5 キオスク表示機能

#### 概要

起動時にキオスクモード相当の全画面表示を行う。シングルディスプレイ環境で、そのディスプレイ全体に表示する。

#### 表示内容

- PDF・画像・動画のみ

#### 非表示・抑制項目

- タイトルバー
- メニューバー
- スクロールバー
- Windows タスクバー
- Alt+Tab 等によるアプリ切替（可能な範囲で抑制）

---

### 3.6 自動起動機能

#### 概要

Windows 起動時にアプリケーションを自動起動する（管理画面で ON/OFF 設定可能）。

#### 動作フロー

```text
PC起動（または指定時刻の電源オン）
↓
Windows ログオン
↓
サイネージアプリ起動
↓
表示開始
```

---

### 3.7 エラーハンドリング

#### 概要

破損ファイルや開けないファイルが存在しても運転を継続する。

#### ファイル読込失敗時の動作

```text
ファイル読込失敗
↓
エラーログ出力（logs フォルダへ保存）
↓
当該ファイルをスキップ
↓
次ファイル表示
```

#### エラーログ出力先

- 監視フォルダ（サイネージデータ）と**同じ階層**に `logs` フォルダを作成し、そこへ出力する
- 例: 監視フォルダが `D:\Signage` の場合、ログは `D:\logs` へ保存
- 監視フォルダを変更した場合、ログ出力先も連動して変更する
- ログは **7 日間**保存し、起動時および監視フォルダ変更時に古いログを自動削除する

#### アプリ異常終了時

- **アプリ内で自己再起動**する

#### 復帰不能時

- 管理画面で設定した固定メッセージを全画面表示する
- 初期メッセージ例: 「表示を復旧しています」

## 4. 画面要件

### 4.1 表示画面

#### 通常モード（キオスク表示）

PDF・画像・動画を全画面表示する。

```text
+--------------------------------+
|                                |
|                                |
|      コンテンツ表示エリア      |
|                                |
|                                |
+--------------------------------+
```

#### 管理モード

管理者のみ利用可能。**`Ctrl+Shift+M`** で通常モードから切り替える。

##### 設定項目（すべて GUI で設定）

| 項目 | 説明 |
|------|------|
| 監視フォルダ | 表示対象フォルダのパス |
| デフォルト表示秒数 | 5〜300 秒 |
| Windows 自動起動 | ON / OFF |
| アプリ終了時刻 | 日次のアプリ終了時刻 |
| PC 電源オフ時刻 | 日次の PC 電源オフ時刻 |
| 復帰不能時メッセージ | 障害時に表示する固定テキスト |
| バージョン情報 | アプリのバージョン表示 |

管理モードから通常モード（キオスク表示）へ戻れること。

## 6. 非機能要件

### 6.1 性能要件

| 項目 | 目標値 |
|------|--------|
| 起動時間 | 30 秒以内 |
| コンテンツ切替時間 | 3 秒以内 |
| メモリ使用量 | 500 MB 以下 |

### 6.2 可用性要件

#### 連続運転

- 24 時間 365 日運用可能

#### 障害発生時

- アプリ異常終了時はアプリ内で自己再起動
- 復帰できない場合は、管理画面で設定した固定メッセージを表示

### 6.3 保守性要件

#### コンテンツ更新

利用者はファイルをフォルダへ保存するのみ。専門知識を不要とする。

#### システム設定

管理者は管理モード（`Ctrl+Shift+M`）から GUI で各種設定を行う。

## 9. 初期リリース範囲（MVP）

以下の機能を実装対象とする。

- PDF・JPEG・MP4 の表示
- PDF 複数ページ対応（ページ順表示）
- ファイル名末尾による個別表示時間（`_秒数`、動画除く）
- 動画は再生完了まで表示
- キオスクモード全画面表示（タスクバー・Alt+Tab 等の抑制）
- 自動切替・ループ表示
- フォルダ監視（現在スライド表示後に反映）
- スケジュール終了・アプリ終了・PC 電源オフ
- Windows 自動起動
- エラー時スキップ・エラーログ出力
- アプリ異常終了時の自己再起動
- 復帰不能時の固定メッセージ表示（メッセージは GUI で設定）
- 管理設定画面（全設定項目を GUI で提供）
- C# / WPF によるポータブル exe 配布

## 10. MVP 開発方針

初期リリースでは「誰でも運用できること」を最優先とする。

**コンテンツ担当者**は以下の運用のみで表示内容を管理する。

```text
ファイル作成
↓
指定フォルダに保存
↓
自動反映
↓
サイネージ表示
```

**システム管理者**は `Ctrl+Shift+M` から管理画面を開き、フォルダパス・表示時間・スケジュール・障害メッセージ等を GUI で設定する。コンテンツの追加・削除はフォルダ操作のみで完結し、日常運用に専門知識を不要とする。
