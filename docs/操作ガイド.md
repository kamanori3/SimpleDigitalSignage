# 操作ガイド（簡単！シンプル！サイネージ）

サイネージ用 PC での日常操作を説明します。専門知識は不要です。

| 対象 | 主な作業 |
|------|----------|
| **コンテンツ担当者** | 表示したいファイルをフォルダに入れる・削除する |
| **システム管理者** | フォルダの場所・表示時間・夜間停止・アクセスキーなどを設定する |

技術的な詳細（ログ・権限・制限事項）は [運用ガイド](運用ガイド.md) を参照してください。

---

## 1. 表示のしくみ（全体像）

```text
① 指定フォルダにファイルを置く（PDF・画像・動画）
        ↓
② アプリが自動で検知
        ↓
③ 全画面で順番に表示（ループ）
```

- ファイルを**追加・削除**すると、**いま表示しているスライドが終わったあと**に内容が更新されます。
- 普段は全画面表示（キオスクモード）のまま運用します。

---

## 2. コンテンツ担当者向け

### 2.1 表示するファイルを追加する

1. 監視フォルダを開く（本番の例: `D:\Signage`）
2. 表示したいファイルを**フォルダの直下**にコピーまたは保存する
3. しばらくすると（現在のスライド表示後）自動で表示に反映される

**サブフォルダの中のファイルは表示されません。** 必ずフォルダ直下に置いてください。

### 2.2 表示を止めたい・内容を減らしたい

監視フォルダから、表示したくないファイルを**削除**してください。反映も現在のスライド表示後です。

### 2.3 使えるファイルの種類

| 種類 | 拡張子 | 表示のしかた |
|------|--------|--------------|
| 画像 | `.jpg` / `.jpeg` | 1 ファイル = 1 枚のスライド |
| PDF | `.pdf` | 1 ページ = 1 枚のスライド（ページ順） |
| 動画 | `.mp4` | 最後まで再生してから次へ |

※ PNG・GIF・MOV などは**使えません**。

### 2.4 表示順（どのファイルから出すか）

ファイル名の**昇順**で表示します。数字の部分は数値として比べるので、`001` → `002` → `010` の順になります。

| ファイル名の例 | 表示順 |
|----------------|--------|
| `001.jpg` → `002.jpg` → `010.jpg` | 001 → 002 → 010 |
| `1.jpg` → `2.jpg` → `10.jpg` | 1 → 2 → 10（数値の昇順） |

先頭を `001` `002` … のように桁を揃えると、意図どおりの昇順になり管理しやすいです。

### 2.5 表示時間を変えたい（ファイル名で指定）

画像・PDF は、ファイル名の**末尾**（拡張子の直前）に `_秒数` を付けると、その秒数だけ表示できます。使える秒数は **5〜300** です。

| ファイル名 | 意味 |
|----------|------|
| `案内.pdf` | 管理者が設定した標準の秒数（初期値 15 秒） |
| `案内_120.pdf` | **120 秒**（2 分）表示 |
| `写真_30.jpg` | **30 秒**表示 |

- 動画（`.mp4`）は**再生が終わるまで**表示します（秒数指定は無効）。
- 秒数は**ファイル名の末尾**だけが対象です。`120_案内.pdf` のように途中にある数字は使いません。

### 2.6 再生期限を付けたい（ファイル名で指定）

ファイル名の**末尾**に `_年月日`（8 桁、例: `_20260904`）を付けると、その日まで再生し、翌日から表示しなくなります。フォルダからファイルは消えません。

秒数と期限は**どちらを先に書いても**よく、必ず**末尾にまとめて**付けます。

| ファイル名 | 意味 |
|----------|------|
| `案内_20260904.pdf` | 標準の秒数で、**2026年9月4日まで**再生 |
| `案内_20_20260212.pdf` | **20 秒**表示、**2026年2月12日まで**再生 |
| `案内_20260102_30.pdf` | **30 秒**表示、**2026年1月2日まで**再生 |

- 期限日**当日は最後まで再生**します。翌日から対象外です。
- 動画も期限の対象です（秒数指定は無効のまま）。
- 指定を間違えても再生は止まりません。誤った指定だけ無視します（秒数なら標準の秒数、日付なら期限なし）。
- 誤りがあると、管理者が管理画面を開くたびにメッセージボックスで知らせます。案内の例は `○○_20261231`、`○○_20_20260212` です。

よくある誤り:

| ファイル名の例 | 扱い |
|----------------|------|
| `案内_20261301.pdf`（存在しない日付） | 期限なしで再生。管理画面でアラート |
| `案内_2026923.pdf`（日付が 7 桁） | 期限なしで再生。正しい形は `_20260923`。管理画面でアラート |
| `写真_4.jpg`（5 秒未満） | 標準の秒数で再生。管理画面でアラート |
| `案内_20_30.pdf`（秒数が 2 つ） | 標準の秒数で再生。管理画面でアラート |
| `案内_20260101_20260202.pdf`（期限が 2 つ） | 期限なしで再生。管理画面でアラート |
| `IMG_2716.jpg`（カメラの番号など） | 秒数でも期限でもないので無視（誤りではない・アラートなし） |

### 2.7 コンテンツ担当者の注意事項

- ファイルのコピー途中だと読み込みに失敗することがあります。コピー完了後に反映されます。
- 壊れたファイルは自動でスキップされ、他のファイルは続けて表示されます。管理画面を開くと、対象ファイル名をメッセージボックスで知らせます。
- 期限が切れたファイルは自動で表示されなくなります。フォルダに残したままでも構いません。
- 表示内容の設定変更（フォルダの場所・標準の秒数など）は**管理者**が管理画面で行います。

## 3. システム管理者向け

### 3.1 アプリの起動

1. 配布フォルダ内の **`PdfSignage.exe`** をダブルクリック
2. 全画面でサイネージ表示が始まります（初回は設定ファイルが自動作成されます）

### 3.2 管理画面を開く

キオスク表示中に、次のキーを**同時に**押します。

```text
Ctrl ＋ Shift ＋ M
```

管理画面（設定画面）が開きます。キオスクの全画面表示はいったん隠れます。

ファイル名の秒数・期限の指定に誤りがあると、**管理画面を開くたびに**メッセージボックスで知らせます（タイトル「表示期限の指定」）。本文は次の案内と、対象ファイル名の一覧です。

```text
このファイルの表示期限の指定方法が誤っていますのでファイル名を修正してください。
例）○○_20261231、○○_20_20260212
```

壊れていて表示できないファイルがあると、続けてメッセージボックスで知らせます（タイトル「壊れたファイル」）。本文は次の案内と、対象ファイル名の一覧です。

```text
このファイルは壊れているため表示できません。正しいファイルに差し替えてください。
```

キオスク再生中には出ません。再生は止まらず、誤った指定は無視、壊れたファイルはスキップされます。コピーの途中で開くと、一時的に「壊れたファイル」と出ることがあります。

### 3.3 キオスク表示に戻る

管理画面で **「通常モード（キオスク）に戻る」** をクリックするか、再度 `Ctrl ＋ Shift ＋ M` を押します。

### 3.4 設定を保存する

管理画面で値を変更したら、必ず **「保存して設定する」** をクリックしてください。

- 設定はすぐにアプリへ反映されます（再起動は不要）。
- 画面下部に緑色のメッセージが出れば保存成功です。赤色の場合は入力内容を確認してください。

### 3.5 管理画面の設定項目

| 設定項目 | 説明 |
|----------|------|
| **監視フォルダ** | コンテンツを置くフォルダのパス。「参照…」で選択も可能。この PC 内のフォルダを指定する |
| **デフォルト表示秒数** | 画像・PDF の標準表示時間（5〜300 秒） |
| **Windows 起動時に自動起動** | ON にすると、PC 起動・ログオン後にアプリが自動で立ち上がる |
| **アプリ終了時刻** | 毎日、指定時刻にアプリを終了する（例: `18:00`）。無効にすれば終了しない |
| **PC 電源オフ時刻** | 毎日、指定時刻に PC の電源を切る（例: `18:03`）。無効にすれば電源オフしない |
| **復帰不能時メッセージ** | すべてのファイルが表示できないとき、全画面に出す文言 |
| **ライセンス** | 試用中 / 契約中 / 期限切れと、期限日・残り日数（表示のみ） |
| **アクセスキー** | メールで届いた文字列を貼り付け、「アクセスキーを適用」で有効化する |
| **ログフォルダ** | 障害調査用ログの場所（表示のみ。クラウドには送らない） |

#### 時刻の入力形式

- `HH:mm`（24 時間制）
- 例: 午後 6 時 → `18:00`、午前 9 時 30 分 → `09:30`

#### PC 電源オフ時刻の初期値

アプリ終了時刻を有効にすると、PC 電源オフは**アプリ終了の 3 分後**が初期値になります（変更可能）。

### 3.6 夜間停止・朝の自動起動（スケジュール）

よくある設定例:

| 時刻 | 動作 |
|------|------|
| 18:00 | アプリ終了 |
| 18:03 | PC 電源オフ（任意） |
| 翌朝 PC 起動後 | Windows 自動起動 ON ならアプリが起動し、表示開始 |

```text
夜   アプリ終了 →（設定時）PC 電源オフ
朝   PC 起動 → ログオン → アプリ自動起動 → サイネージ開始
```

PC 電源オフが失敗する場合は、ログに記録されます。社内の PC 管理ポリシーを確認してください。

### 3.7 アプリを終了する

| 方法 | 手順 |
|------|------|
| 管理画面から | `Ctrl ＋ Shift ＋ M` → **「アプリを終了」** |
| 管理画面を閉じる | 管理画面の × ボタンで閉じるとアプリも終了 |

スケジュールで設定した終了時刻に到達した場合も、自動で終了します。

### 3.8 ログの場所（障害時）

表示に問題があるとき、管理者はログを確認できます。

| 項目 | 内容 |
|------|------|
| 場所 | この PC の `%LocalAppData%\PdfSignage\logs`（監視フォルダとは別） |
| 例 | `C:\Users\（ユーザー名）\AppData\Local\PdfSignage\logs` |
| 保存期間 | **7 日間**（古いログは自動削除） |

管理画面にも同じパスが出ます。問い合わせのときは、このフォルダのログをメールに添付してください。

### 3.9 ライセンス（試用・アクセスキー）

この Windows ユーザーでアプリが**初めて起動した日**から **60 日間**は、無料で通常表示できます（当日を含みます。例: 9月12日起動 → 11月10日まで）。

試用または契約の期限が切れると、映像は止まらず、画面の下端に次の案内が出ます。

> 契約期限が切れています。更新のうえ、管理画面（Ctrl+Shift+M）にアクセスキーを入力してください。

届いたアクセスキーを管理画面に貼り付け、「アクセスキーを適用」を押してください。正しければ案内は消え、契約期限が表示されます。誤ったキーでは以前の状態のままです。

同じ PC・同じユーザーでは、配布フォルダや `settings.json` を消しても試用期間は延びません。別の PC では、その PC の初回起動から新たに 60 日です。

## 4. よくある質問

### Q. ファイルを入れたのにすぐ変わらない

**A.** いま表示中のスライドが終わるまで待ちます。動画の場合は再生完了までかかります。

### Q. サブフォルダに入れたファイルが出ない

**A.** 監視フォルダの**直下**だけが対象です。一つ上のフォルダに移動してください。

### Q. 管理画面が開けない

**A.** `Ctrl` `Shift` `M` を**同時に**押してください。キオスク表示の画面がアクティブな状態で試してください。

### Q. 画面に「表示を復旧しています」と出る

**A.** フォルダ内のファイルがすべて読み込めない状態です。ファイルの破損・形式の誤りを確認してください。表示文言は管理画面の「復帰不能時メッセージ」で変更できます。

### Q. 期限を過ぎたファイルは消えますか

**A.** フォルダからは消えません。指定した日までは再生し、翌日から表示対象外になります。不要ならフォルダから削除してください。日付が変わったあとの反映は、いま表示中のスライドが終わってからです。

### Q. ファイル名の秒数や期限を間違えた

**A.** 再生は続きます。管理画面（`Ctrl ＋ Shift ＋ M`）を開くたびに、「表示期限の指定」ダイアログで修正例（`○○_20261231`、`○○_20_20260212`）と対象ファイル名が表示されます。日付は必ず 8 桁（例: `_20260923`）にしてください。

### Q. 壊れたファイルがあるかどうか知りたい

**A.** 管理画面（`Ctrl ＋ Shift ＋ M`）を開くたびに、「壊れたファイル」ダイアログで対象ファイル名が表示されます。再生は続き、壊れたファイルだけ飛ばします。コピーの途中で開くと一時的に出ることがあるので、コピー完了後に再度開いて確認してください。

### Q. 動画だけ表示時間を短くしたい

**A.** 動画は**再生完了まで**表示します。秒数指定はできません。短くしたい場合は動画自体を編集してください。再生を止めたい日がある場合は、ファイル名に `_20260904` のような期限を付けてください。

### Q. 複数の PC で同じフォルダを見せたい

**A.** 既定では、各 PC の中にあるフォルダだけを監視フォルダにできます。複数台で同じファイルを見せたい場合は、各 PC のローカルフォルダへ同じファイルを置いてください。ネットワーク共有を使う運用は将来のネットワーク商品向けで、`settings.json` の切替と正式サポートが別途必要です。

### Q. 画面の下に「契約期限が切れています」と出る

**A.** 試用または契約の期限が切れています。表示はそのまま続きます。届いたアクセスキーを、管理画面（`Ctrl ＋ Shift ＋ M`）に貼り付けて「アクセスキーを適用」してください。

## 5. 操作の早見表

### コンテンツ担当者

| やりたいこと | 操作 |
|--------------|------|
| 表示を追加 | 監視フォルダ直下にファイルを保存 |
| 表示を削除 | 監視フォルダからファイルを削除 |
| 表示順を変える | ファイル名を変更（001, 002…） |
| 表示時間を変える | ファイル名の末尾に `_秒数` を付ける（動画除く） |
| 再生期限を付ける | ファイル名の末尾に `_20260904` のような日付を付ける |

### システム管理者

| やりたいこと | 操作 |
|--------------|------|
| 設定を変更 | `Ctrl ＋ Shift ＋ M` → 変更 → 「保存して設定する」 |
| ファイル名の誤り・壊れたファイルを確認 | `Ctrl ＋ Shift ＋ M`（入場時のメッセージボックス） |
| キオスクに戻る | 「通常モード（キオスク）に戻る」または `Ctrl ＋ Shift ＋ M` |
| アプリを終了 | 管理画面「アプリを終了」 |
| 朝自動で起動 | Windows 自動起動を ON |
| 夜に停止 | アプリ終了時刻・PC 電源オフ時刻を設定 |
| アクセスキーを入れる | `Ctrl ＋ Shift ＋ M` → 貼り付け → 「アクセスキーを適用」 |
| ログの場所を確認 | 管理画面の「ログフォルダ」 |
