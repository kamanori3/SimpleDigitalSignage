# 運用ガイド（簡易デジタルサイネージ）

現場投入時のフォルダ運用・管理・ログ・権限の要点。

## 配布・初回セットアップ

1. `publish/PdfSignage-win-x64` フォルダ一式を現場 PC にコピー
2. `PdfSignage.exe` を起動（初回で `settings.json` が自動作成）
3. `Ctrl+Shift+M` で管理画面を開き、監視フォルダ・表示秒数等を設定
4. コンテンツを監視フォルダに配置

テンプレート: `settings.example.json`

```powershell
# 配布ビルドの作成（開発環境）
.\scripts\publish.ps1
```

## コンテンツ担当者の運用

監視フォルダ（本番例: `D:\Signage`）の**直下**にファイルを置く・削除するだけ。

| 種別 | 拡張子 |
|------|--------|
| 画像 | `.jpg`, `.jpeg` |
| PDF | `.pdf` |
| 動画 | `.mp4` |

- サブフォルダ内のファイルは対象外
- ファイル名は自然順（`001`, `002`, `010` の順）
- 表示秒数の上書き: 拡張子直前の `_数字`（例: `案内_120.pdf` → 120 秒）。動画は再生完了まで

変更は**現在表示中のスライドが終わった後**に反映される。

## システム管理者

| 操作 | 方法 |
|------|------|
| 管理画面を開く | キオスク表示中に `Ctrl+Shift+M` |
| キオスクに戻る | 管理画面「通常モード（キオスク）に戻る」または再度 `Ctrl+Shift+M` |
| 設定を保存 | 「保存して設定する」→ `settings.json` に保存・即時反映 |
| アプリ終了 | 管理画面「アプリを終了」または管理画面を × で閉じる |

### 管理画面で設定できる項目

- 監視フォルダパス
- デフォルト表示秒数（5〜300）
- Windows 起動時の自動起動 ON/OFF
- アプリ終了時刻（日次・HH:mm）
- PC 電源オフ時刻（日次・HH:mm）
- 復帰不能時メッセージ

## ログ

| 項目 | 内容 |
|------|------|
| 出力先 | 監視フォルダと**同じ階層**の `logs`（例: `D:\Signage` → `D:\logs`） |
| ファイル名 | `app_YYYYMMDD.log`（日次） |
| 保存期間 | **7 日間**（起動時・監視フォルダ変更時に古いログを自動削除） |
| 監視フォルダ変更時 | ログ出力先も連動して変更 |

起動・スライド切替・エラー・スケジュール実行が記録される。障害調査時は ERROR 行と前後の INFO を確認する。

## スケジュール運用（夜間停止・朝の自動起動）

1. 管理画面でアプリ終了時刻・PC 電源オフ時刻を設定（任意）
2. Windows 自動起動を ON にすると、ログオン後にアプリが起動する

典型フロー:

```text
夜: アプリ終了 →（任意）PC 電源オフ
朝: PC 起動 → Windows ログオン → アプリ自動起動 → 表示開始
```

PC 電源オフは `shutdown /s /t 0` を実行する。失敗時はログに記録される。

## 権限・環境要件

| 項目 | 要件 |
|------|------|
| OS | Windows 11（win-x64） |
| .NET | 配布版は self-contained（ランタイム同梱） |
| 監視フォルダ | 読み取り権限 |
| ログフォルダ | 書き込み権限 |
| PC 電源オフ | 通常は標準ユーザーで可。グループポリシーにより拒否される場合あり |
| Windows 自動起動 | レジストリ `HKCU\...\Run` への書き込み（標準ユーザーで可） |

## 性能目標（受け入れ基準）

| 指標 | 目標 |
|------|------|
| 起動〜初回表示 | 30 秒以内 |
| スライド切替 | 3 秒以内（ログ `スライド切替: ... (Nms)` で確認） |
| メモリ | 500 MB 以下（長時間運転後） |

## 既知の制限事項

| 項目 | 説明 |
|------|------|
| Alt+Tab 完全抑制 | OS 制約により完全な抑制は不可。可能な範囲で抑制 |
| シングルディスプレイ | プライマリ画面に固定。マルチモニタの個別制御は未対応 |
| 監視フォルダ | 直下のみ。サブフォルダ・UNC パスは将来拡張 |
| 対応形式 | JPEG / PDF / MP4 のみ（PNG・GIF・MOV 等は未対応） |
| PC 電源オフ | ポリシー・権限により `shutdown` が失敗する環境がある |
| 自己再起動 | 再起動直後 30 秒以内の再クラッシュは再起動しない（ループ防止） |
| 二重起動 | 同一 PC で複数インスタンスは起動しない（Mutex） |
