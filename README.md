# 簡単！シンプル！サイネージ

PDF・画像・動画をフォルダに置くだけで運用できる Windows 向けデジタルサイネージ（WPF / C#）。ソリューションは `KS_Signage.sln`、実行ファイルは `KS_Signage.exe` です。

指定したフォルダを監視し、`.jpg` / `.jpeg` / `.pdf` / `.mp4` を全画面で順番にループ表示します。コンテンツの更新はファイルをコピーするだけ、設定は `Ctrl+Shift+M` の管理画面からすべて GUI で行えます。

## 開発

```powershell
cd KS_Signage
dotnet run
```

`D:\Signage` が存在しない開発 PC では、監視フォルダは自動的に `{出力フォルダ}/SignageData` にフォールバックします。

コンテンツ表示モード中に `Ctrl+Shift+M` で管理画面。

アクセスキーの発行（販売側。現場配布には含めない）:

```powershell
dotnet run --project KS_Signage.Issuer
```

フォームに通し番号・プラン・期限を入れて発行する。作成済みキーの一覧も同じ画面に出る。手順の正は [アクセスキー発行](docs/アクセスキー発行.md)。

### テスト

```powershell
dotnet test
```

対象は外部依存を持たない純粋ロジック（表示秒数・再生期限の解析、自然順ソート、スケジュール時刻、入力検証、パス解決、アクセスキーの検証と課金状態判定）と、一時ファイルを使う破損判定（`ContentFileProbe`）。UI とフォルダ監視を伴う部分は [受け入れテスト](docs/受け入れテスト.md) の手動確認でカバーしています。

## ポータブル配布（Release）

```powershell
.\scripts\publish.ps1
```

出力先: `publish/KS_Signage-win-x64/`

- self-contained（.NET ランタイム同梱）
- フォルダ一式を現場 PC にコピーして `KS_Signage.exe` を起動
- 初回起動で `settings.json` が自動作成される（テンプレート: `KS_Signage/settings.example.json`）
- **配布先は書き込み権限のある場所に置くこと**（`settings.json` を exe と同じ場所に保存するため）

## 動作要件

- Windows 11（win-x64）、シングルディスプレイ
- 開発時: .NET 8 SDK
